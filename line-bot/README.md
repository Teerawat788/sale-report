# บอท LINE ผู้ช่วยทีมขาย

บอทที่เชิญเข้ากลุ่ม LINE ของทีมขาย เพื่อช่วยงานพวกนี้:

| ฟีเจอร์ | ทำอะไร |
|---|---|
| 📊 **สรุปยอด** | ดึงยอดจาก `dashboard.json` (ไฟล์เดียวกับหน้า Sales Command Center) แล้วสรุปให้ เช่น % ทำได้, เทียบ Time gone, Forecast, สปีดที่ต้องเร่ง, แยก Fish 4 / Fish 5 |
| 📋 **ติดตามงาน** | สั่งงานในกลุ่มพร้อม @mention ผู้รับผิดชอบและวันกำหนดส่ง ดูงานค้าง/งานเลยกำหนด แล้วปิดงานได้ |
| 📅 **Agenda / ปฏิทิน** | เพิ่มนัดลง Google Calendar จากแชท ดูนัดวันนี้/พรุ่งนี้/สัปดาห์นี้ และ**เตือนก่อนถึงนัด 30 นาที** |
| 🔁 **งานประจำสัปดาห์** | เช็กลิสต์ที่วนทุกสัปดาห์ (เช่น ส่งรายงานทุกจันทร์) ติ๊กว่าทำแล้ว และขึ้นสัปดาห์ใหม่จะเริ่มนับใหม่เอง |
| ☀️ **สรุปเช้าอัตโนมัติ** | ทุกเช้าวันทำงาน: นัดวันนี้ + งานถึงกำหนด/เลยกำหนด + งานประจำที่ยังไม่ทำ + ยอดสั้น ๆ (วันจันทร์จะมีแผนทั้งสัปดาห์) |
| 📈 **สรุปสัปดาห์อัตโนมัติ** | ทุกศุกร์ 16:00: งานที่ปิดได้, งานค้าง, งานประจำที่ยังไม่ทำ, นัดสัปดาห์หน้า, ยอด |

ใช้ **Google Apps Script** ทั้งหมด จึงไม่ต้องมีเซิร์ฟเวอร์และไม่มีค่าใช้จ่ายฝั่ง Google
- งานติดตาม/งานประจำ เก็บใน **Google Sheet** (แท็บ `Tasks`, `Weekly`) เปิดแก้ไขใน Sheet ได้เลย
- นัดเก็บใน **Google Calendar** (นัดที่เพิ่มจากแอป Calendar เองก็ขึ้นในบอทด้วย)

## ติดตั้ง (ประมาณ 20 นาที)

### 1) สร้าง LINE Official Account + Messaging API
1. เข้า [LINE Developers Console](https://developers.line.biz/console/) → สร้าง Provider → สร้าง channel แบบ **Messaging API**
2. แท็บ **Messaging API** → ออก **Channel access token (long-lived)** → คัดลอกไว้
3. ในหน้าเดียวกัน (หรือใน LINE Official Account Manager → ตั้งค่าการตอบกลับ):
   - เปิด **Allow bot to join group chats**
   - ปิด **Auto-reply messages** และ **Greeting messages**
   - เปิด **Use webhook** (ใส่ URL ในขั้นที่ 3)

### 2) สร้าง Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ เช่น "Sales Bot" → เมนู **ส่วนขยาย → Apps Script**
2. **Project Settings** (ไอคอนเฟือง) → ติ๊ก *Show "appsscript.json" manifest file* → ตั้ง Time zone เป็น `(GMT+07:00) Bangkok`
3. **วิธีง่ายสุด:** เปิด [`dist/Code.gs`](dist/Code.gs) บน GitHub → กดปุ่ม **Copy raw file** (ไอคอนสี่เหลี่ยมซ้อนมุมขวาบน) → ไปที่ไฟล์ `Code.gs` ใน Apps Script ลบของเดิมแล้ววาง → กด 💾 บันทึก
   แล้วทำแบบเดียวกันกับ [`src/appsscript.json`](src/appsscript.json) วางทับไฟล์ `appsscript.json`
   - หรือใช้ [clasp](https://github.com/google/clasp): คัดลอก `.clasp.json.example` เป็น `.clasp.json`, ใส่ Script ID, แล้ว `clasp push`
4. **Project Settings → Script Properties** เพิ่ม:

| Property | ค่า |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | token จากขั้นที่ 1 (**จำเป็น**) |
| `CALENDAR_ID` | (ไม่บังคับ) ID ปฏิทินทีม — แนะนำสร้างปฏิทิน "ทีมขาย" ใน Google Calendar แล้วแชร์ให้ทุกคน ดู ID ได้ที่ ตั้งค่าปฏิทิน → *รวมปฏิทิน* ถ้าเว้นว่างจะใช้ปฏิทินหลักของคนที่ติดตั้ง |
| `DASHBOARD_URL` | (ไม่บังคับ) ค่าเริ่มต้นคือ `dashboard.json` ใน branch `main` ของ repo นี้ |
| `MORNING_HOUR` | (ไม่บังคับ) ชั่วโมงส่งสรุปเช้า ค่าเริ่มต้น `7` |
| `WORK_DAYS` | (ไม่บังคับ) วันที่ส่งสรุปเช้า `0`=อา … `6`=ส ค่าเริ่มต้น `1,2,3,4,5,6` |
| `REMIND_BEFORE_MIN` | (ไม่บังคับ) เตือนก่อนนัดกี่นาที ค่าเริ่มต้น `30` |
| `BRIEF_ENABLED` / `REVIEW_ENABLED` / `REMINDER_ENABLED` | (ไม่บังคับ) ใส่ `false` เพื่อปิดการส่งอัตโนมัติแต่ละแบบ |

5. ในหน้า editor เลือกฟังก์ชัน **`showBotInfo`** → Run → อนุญาตสิทธิ์ (ครั้งแรก Google จะเตือน "unverified app" ให้กด Advanced → Go to …) ฟังก์ชันนี้จะบันทึก `BOT_USER_ID` ให้เอง (ใช้กรอง webhook ที่ไม่ได้มาจาก LINE ของเรา)
6. เลือกฟังก์ชัน **`setupTriggers`** → Run (ตั้งเวลาสรุปเช้า, เตือนนัดทุก 10 นาที, สรุปวันศุกร์)

### 3) Deploy เป็น Web app แล้วผูกกับ LINE
1. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
2. คัดลอก Web app URL (`https://script.google.com/macros/s/.../exec`) ไปใส่ช่อง **Webhook URL** ใน LINE Developers → เปิด **Use webhook**
   - ปุ่ม *Verify* อาจขึ้น error เพราะ Apps Script ตอบแบบ redirect — ถ้าทักบอทแล้วบอทตอบได้ถือว่าใช้งานได้
3. เชิญบอทเข้ากลุ่ม LINE ทีมขาย → พิมพ์ **`ลงทะเบียน`** (บอทจะส่งแจ้งเตือนอัตโนมัติเข้ากลุ่มนี้กลุ่มเดียว และจะไม่ตอบคำสั่งในกลุ่มอื่น)
4. พิมพ์ **`เมนู`** เพื่อเริ่มใช้

> แก้โค้ดแล้วต้อง **Deploy → Manage deployments → ✏️ → Version: New version** เพื่อให้ URL เดิมใช้โค้ดใหม่

## ⚠️ เรื่องโควตาข้อความของ LINE OA

- **การตอบคำสั่ง (reply) ไม่เสียโควตา** — ใช้ได้ไม่จำกัด
- **ข้อความที่บอทส่งเอง (สรุปเช้า, เตือนนัด, สรุปศุกร์) เป็น push** ซึ่งนับโควตารายเดือน และ **นับตามจำนวนสมาชิกในกลุ่ม** (ส่ง 1 ครั้งในกลุ่ม 10 คน = 10 ข้อความ)
- แพ็กเกจฟรีมีโควตาน้อย ถ้ากลุ่มใหญ่และเปิดครบทุกอย่าง โควตาฟรีอาจหมดกลางเดือน ทางเลือก:
  - อัปเกรดแพ็กเกจ LINE OA (ดูราคาปัจจุบันใน LINE Official Account Manager)
  - หรือปิดบางอย่าง เช่น `REMINDER_ENABLED=false` (เตือนนัดใช้โควตามากที่สุด) แล้วให้ทีมพิมพ์ `สรุปเช้า` / `วันนี้` เอง ซึ่งไม่เสียโควตา
- ถ้าโควตาหมด คำสั่งแบบตอบกลับยังใช้ได้ตามปกติ

## ยอดขายรายวันจาก Power BI

บอทอ่านยอดรายวันจากแท็บ **SalesData** ใน Google Sheet ถ้ามีข้อมูล (ถ้าไม่มีจะใช้ `dashboard.json` เหมือนเดิม)

```
Power BI → Export data (.csv) → โฟลเดอร์ Google Drive → บอทดึงเข้า SalesData ทุกชั่วโมง → คำนวณยอด
```

**ตั้งค่าครั้งเดียว**
1. สร้างโฟลเดอร์ใน Google Drive (เช่น "Sales Bot - Power BI Export") แล้วคัดลอก ID จาก URL (`drive.google.com/drive/folders/<ID>`)
2. Script Properties → เพิ่ม `IMPORT_FOLDER_ID` = ID นั้น
3. วาง `dist/Code.gs` และ `src/appsscript.json` ใหม่ (เพิ่มสิทธิ์ Google Drive) → รัน `setupTriggers` อีกครั้งและกดอนุญาต
   แท็บ `SalesData` และ `Targets` จะถูกสร้างให้อัตโนมัติ
4. กรอกเป้าในแท็บ **Targets**: `เดือน (yyyy-mm)` | `ทีม/เขต` | `เซลส์` (ว่าง = เป้าทั้งเขต) | `เป้า (ตัน)` | `เป้า (ล้านบาท)`
   เช่น `2026-11 | F1 | | 500 | 10.5` — ใส่ครบ F1–F5 ยอดรวมทุกเขตจะรวมให้เอง
5. (ไม่บังคับ) `HOLIDAYS` = วันหยุดที่ไม่นับวันทำงาน เช่น `5/12,10/12,31/12`

**ฟอร์มหลัก (ไฟล์ที่ส่งทุกวัน)** — ยอดสะสมทั้งเดือนรายลูกค้า ไม่มีคอลัมน์วันที่:

| คอลัมน์ | ใช้เป็น |
|---|---|
| `PIC_New` | เซลส์ (ใช้แทน `PIC`; ค่า `#` = ไม่ระบุ PIC) |
| `Area_New` | เขต — `TFM Fish1 North` → **F1** … `TFM Fish5 South` → **F5**, เขต TFM อื่น (Shrimp/Export/Livestock) **ไม่นำมาคิด** — ยอดรวม = F1–F5 |
| `Sold_to_Party_id`, `Sold_to_Party` | ลูกค้า |
| `Actual Volume ThisYY (Ton)` | ตันสะสมของเดือน |
| `Actual Value ...` (ถ้าเพิ่มในอนาคต) | บาทสะสม — รายงานจะแสดงฝั่งบาทให้อัตโนมัติ |

- **วันที่ของข้อมูลเอาจากชื่อไฟล์**: `data_18.xlsx` = ข้อมูลถึงวันที่ 18 (หรือ `2026-11-18`) — ไม่มีเลขในชื่อ = ถึงเมื่อวาน
  ระบุเองได้: `อัปเดตยอด 18/11`
- เก็บไว้ในแท็บ **SalesMTD** (1 ชุดต่อวัน) — **ยอดรายวัน = ยอดสะสมไฟล์วันนี้ − ไฟล์เมื่อวาน**
  (ไฟล์แรกของเดือนจะยังไม่มียอดรายวัน)
- แถว `Total` และข้อความตัวกรองท้ายไฟล์ถูกข้ามให้อัตโนมัติ

**ทุกวัน**
- ใน Power BI สร้าง **ตาราง (Table visual)** ที่มีคอลัมน์ วันที่ / ทีม / เซลส์ / ลูกค้า / สินค้า / ตัน (หรือ kg) — ตั้งเป็นเดือนปัจจุบัน
- `…` ที่มุมตาราง → **Export data** → **Summarized data** → **.csv** → อัปโหลดไฟล์ลงโฟลเดอร์ (ใช้ชื่อเดิมทับได้)
- บอทดึงเองทุกชั่วโมงและก่อนส่งสรุปเช้า หรือพิมพ์ `อัปเดตยอด` เพื่อดึงทันที
- ไฟล์แต่ละรอบจะ **แทนที่ข้อมูลช่วงวันที่เดียวกัน** export ซ้ำทั้งเดือนทุกวันได้ ไม่ซ้ำซ้อน

ชื่อคอลัมน์ยืดหยุ่น เช่น `Invoice Date`/`วันที่`, `Sales Name`/`เซลส์`, `Customer Name`/`ลูกค้า`, `Material`/`สินค้า`,
`Ton`/`ตัน`/`Qty (KG)` (คอลัมน์ที่มี kg จะหาร 1000 ให้อัตโนมัติ) รองรับ .csv, .xlsx และ Google Sheet
วันที่แบบ ด/ด/ป หรือ ด/ว/ป (เดาจากข้อมูล), ปี พ.ศ. ก็ได้

**รายงาน `ยอด`** แสดงรวมทุกเขตและแยก F1–F5 ทั้ง **ตัน** และ **มูลค่า (ล้านบาท)**: ยอดสะสม / เป้า (%), วันทำงานผ่านไป/ทั้งเดือน,
สปีดเฉลี่ยต่อวัน, คาดการณ์ปิดเดือน (สปีด × วันทำงานทั้งเดือน) และ % ของเป้า, ต้องทำต่อวันเท่าไหร่ — 🟢 คาดปิด ≥100% 🟡 95–99% 🔴 <95%

**พิมพ์เฉย ๆ ก็ได้**: `F4` → ยอดเขต F4 · `กบทองฟาร์ม` → ยอดลูกค้ารายนั้น (ตัน, ล้านบาท, สปีด, คาดปิดเดือน, % ของเขต, รายวันล่าสุด)
บอทตอบเมื่อข้อความตรงกับชื่อเขตหรือชื่อลูกค้า **รายเดียว** เท่านั้น — ถ้าคำค้นตรงหลายราย ใช้ `ยอด <คำค้น>` เพื่อดูรายชื่อ

**คำสั่ง**: `ยอด` · `ยอด F1` · `ยอด <ชื่อเซลส์>` · `ยอดเมื่อวาน` · `ยอดเซลส์` · `ยอดลูกค้า` · `ยอดสินค้า` · `อัปเดตยอด`

> ต้องการให้ดึงจาก Power BI อัตโนมัติ 100% (ไม่ต้อง export) ทำได้เมื่อ IT เปิดใช้ Power BI REST API
> (Azure AD app + service principal) หรือ Power Automate Premium — ข้อมูลยังลงแท็บ SalesData เหมือนเดิม คำสั่งบอทไม่ต้องเปลี่ยน

## ข้อมูลยอดขาย (dashboard.json)

บอทอ่าน `dashboard.json` ที่ root ของ repo นี้ (ไฟล์เดียวกับที่หน้าเว็บใช้) ฟิลด์ที่ใช้:
`date`, `workingDaysPassed`, `workingDaysTotal`, `status`, `total.{actualTon,budgetTon,achievement,forecastTon,gapTon,currentSpeed,requiredSpeed}`, `fish4`, `fish5`
และถ้ามี `opportunity`, `watchout`, `summary` (array ของข้อความ) จะแสดงเป็น bullet ท้ายสรุปด้วย
อัปเดตไฟล์นี้ตามรอบปกติ บอทจะเห็นยอดใหม่ทันที (GitHub raw อาจ cache ราว 5 นาที)

## ความปลอดภัย

Apps Script อ่าน header `X-Line-Signature` ไม่ได้ บอทจึงป้องกันด้วย:
1. ตรวจ `destination` ให้ตรงกับ `BOT_USER_ID`
2. รับคำสั่งเฉพาะกลุ่มที่ลงทะเบียน (และแชท 1:1 กับบอท)
3. เปลี่ยนกลุ่มได้เฉพาะผู้ดูแลที่ลบ `GROUP_ID` ใน Script Properties

อย่าแชร์ Web app URL และ Channel access token ต่อสาธารณะ
